## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` (1024×1024, drawn by hand from the day's reporting) to `/output/entry.png`. It runs with no network and is fully deterministic — two runs write identical bytes.
